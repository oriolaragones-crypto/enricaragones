# enricaragones.com

Web professional d'Enric Aragonès (geòleg). Astro + contingut multilingüe (ca/es/en).

- `npm install && npm run dev` — desenvolupament
- `npm run build` — genera `dist/`
- Textos d'interfície: `src/i18n/ui.ts`
- Publicacions: `src/data/publications.json` (una entrada per treball, títol/resum per idioma)
- Biografia (línia de temps): `src/data/timeline.json`
